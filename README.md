# Gym-Fit-IA
Stanco delle solite schede copia-incolla? GymFit AI è la web app scientifica che crea il tuo programma di allenamento su misura in pochi secondi. Inserisci i tuoi dati, scegli i giorni e ottieni una scheda perfetta per ipertrofia o forza, pronta da scaricare in PDF. Smetti di sperare, programma i tuoi risultati!
